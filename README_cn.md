# GPA-成绩计算器

一个轻量的 GPA 计算工具，支持 **重修识别**、**政治课标记**，并提供 **命令行版本** 与 **Qt 图形界面版本**。

🇺🇸 **English README available here:**  
👉 https://github.com/NPgreatest/GPA-Calculator/README.md  
（使用时请替换成你真实的仓库链接）

---

## 一、命令行版本

### 📍 成绩单放置位置

将文件保存为：

```

D:\transcript.txt

```

### 📍 文件格式

```
<课程名> <学分> <分数> <是否政治课> <是否重修>

```

示例：

```
大学英语Ⅱ 2.0 67 0 0
钢琴音乐赏析 1.5 80 0 0
高等数学（下） 6.0 70 0 1
高等数学（下） 6.0 98 0 0
数据库原理 3.0 92 0 0
```

### ⚠️ 重修规则

- 重修课程必须 **排在初修之前**
- 课程名必须完全一致
- 程序会自动识别并选择正确成绩（最高或最新）

---

## 二、Qt 图形化版本

Qt 版本提供：

- 成绩单批量导入  
- 自动识别重修（按名字匹配）  
- 按 ECUST 或自定义规则计算 GPA  
- 标记、编辑、批量修改功能  
- 直观简洁的界面  

### 📍 Qt 成绩单格式（更简洁）

```

课程名 学分 分数

```

示例：

```

大学英语Ⅱ 2.0 67
钢琴音乐赏析 1.5 80
高等数学（下） 6.0 70   ← 重修旧成绩
高等数学（下） 6.0 98   ← 最新成绩

```

Qt 会自动识别重修。
